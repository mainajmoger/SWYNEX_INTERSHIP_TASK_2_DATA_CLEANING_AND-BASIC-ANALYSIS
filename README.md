# Data Cleaning and Basic Analysis of Salmonella enterica subsp 23S rRNA Using Python

## 1. Project Overview
This project focuses on basic data cleaning and analysis of the 23S ribosomal RNA (rRNA) sequence of Salmonella enterica subsp. enterica serovar Typhimurium using Python.

## 2. Objective
To retrieve a bacterial nucleotide sequence, check its sequence characters, analyze nucleotide composition, calculate GC content, and visualize the results.

## 3. Dataset Information
- Organism: Salmonella enterica subsp. enterica serovar Typhimurium
- Gene: 23S ribosomal RNA (23S rRNA)
- NCBI Accession Number: NR_076079.2
- Data Source: NCBI Nucleotide Database
- File Format: FASTA

## 4. Tools and Technologies
- Python
- Google Colab
- Biopython
- Pandas
- Matplotlib
- NCBI

## 5. Methodology
1. Retrieved the 23S rRNA sequence from NCBI.
2. Downloaded the sequence in FASTA format.
3. Loaded the sequence using Biopython.
4. Checked the sequence characters for unexpected symbols.
5. Counted the A, T, G, and C nucleotides.
6. Calculated the GC content percentage.
7. Visualized nucleotide composition using a bar graph.
8. Exported the analysis results into a CSV file.

## 6. Project Outputs
- Sequence ID and length
- Sequence character check
- Nucleotide counts
- GC content percentage
- Nucleotide composition bar graph
- CSV file containing analysis results
